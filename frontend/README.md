# Movie Ticket Booking System — Frontend

This directory contains the frontend for our DBMS mini project.

## Technologies
- HTML
- CSS
- JavaScript
- Bootstrap (optional)

## Pages
1. Home Page
2. Movie Details
3. Show Selection
4. Seat Selection
5. Booking Confirmation
6. My Bookings
7. Admin Dashboard

## Development Guidelines
- Use mock data until the backend APIs are ready.
- Keep HTML, CSS, and JavaScript in separate files.
- Follow a consistent, responsive cinema-style design.
- Use the agreed API endpoints when integrating with Flask.
- Do not implement booking validation exclusively in the frontend.

## Integration
The frontend will communicate with a Python Flask backend, which
will retrieve and update information in the MySQL database.
